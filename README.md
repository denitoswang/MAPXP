# Academic Adventure Map

A Phase 1 frontend prototype for a gamified academic progress tracker with an RPG-inspired map UI.

## Overview

This project visualizes academic progression as an adventure map with:
- Main quests representing core courses
- Sidequests representing workshops or extra activities
- XP and level progression
- Node interaction with unlock/completion logic
- Local persistence using `localStorage`

## Files

- `index.html` - Main page layout and structure
- `styles.css` - RPG-themed styling and responsive visuals
- `script.js` - Node interactivity, XP/level logic, and local state persistence

## How to run

1. Open `index.html` in your browser.
2. Click a quest node to view details.
3. Complete unlocked quests to earn XP and progress through levels.

## Notes

- This is a frontend-only Phase 1 prototype.
- No backend or database is included yet.
- Progress is saved locally in the browser.
